# Sprint 1 — Create Trip Route vertical slice

## Scope

1. Route screen in English and Arabic.
2. Airport/city search bottom sheet.
3. Recent and nearby locations.
4. Country and default-currency detection.
5. Same-origin validation.
6. Offline cached metadata state.
7. Versioned API contract and backend persistence.
8. Automated tests and device QA.

## Explicitly out of scope

- Dates and travelers.
- Flight pricing.
- Hotel pricing.
- Final readiness calculation.
