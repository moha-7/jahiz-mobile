# Safaryaty v4.28.6 — Smooth Web Animations Polish

## Scope

Web UI/UX polish only. No core logic changes.

## Added

- Lightweight CSS-only micro animations.
- Softer page, modal, wizard, and card entrance transitions.
- Hover/active states for buttons, tabs, trip cards, payment rows, quick-add cards, and KPI cards.
- Progress bar transition polish.
- Subtle one-time pulse for positive score states.
- Focus polish for form fields.
- Full `prefers-reduced-motion` support.

## Not touched

- `engine.js`
- `payments.js`
- `canTravel.js`
- backend schema
- installments logic
- To Pay logic
- currency logic
- API contracts

## Product rule

Animations should help the user feel flow and feedback. They should not become decoration that slows the app or distracts from decisions.
