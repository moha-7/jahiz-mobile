# Jahiz Design System v0.1

## Identity

- English: `Jahiz`
- Arabic: `جاهز`
- Promise: know whether the trip is financially ready, what is missing and what to do next.

## Visual direction

Premium travel-fintech, calm, clear, trustworthy and Middle East friendly.

The coded tokens live in `packages/design-tokens` and are the source of truth for color, spacing, shape, typography and motion.

## Bilingual rules

- English uses LTR.
- Arabic uses natural RTL copy.
- Airport codes, currency codes, years and score fractions remain LTR.
- Components use logical start/end behavior rather than hardcoded left/right behavior.
- Color never communicates a financial state without text.
