# Jahiz Mobile

Expo SDK 57 / React Native 0.86 foundation with Expo Router and Tamagui 2.

```bash
npm install
npm run mobile:start
```

The first runnable references are:

- Today dashboard, bilingual in-memory preview.
- Create Trip route screen with shared Zod contract validation.
- Bottom tab shell for Today, Plan, Payments and Profile.

The language toggle currently demonstrates layout/copy behavior without forcing a native application restart. Persistent locale selection and operating-system RTL switching are scheduled for Sprint 1.
