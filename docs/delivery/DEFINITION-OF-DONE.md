# Definition of Done

A feature is Done only when:

- English LTR and Arabic RTL are verified.
- iOS and Android behavior is verified.
- Loading, empty, error and validation states exist.
- API integration and persistence work.
- Unit/contract tests pass.
- Accessibility labels and minimum touch targets are present.
- Copy, currency and country behavior are not hardcoded into reusable logic.
- Design review and manual QA pass.
- CI and Docker build gates pass.
